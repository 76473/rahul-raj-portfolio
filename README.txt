Rahul Raj Portfolio
===================

Open index.html in a browser to preview.

The site includes academic summaries, Forage job simulations, and completed portfolio practice projects. Project files are in assets/projects/.

Publishing with GitHub Pages:
1. Create a public repository.
2. Upload the contents of this folder (index.html, README.txt, and assets/).
3. In Settings > Pages, choose Deploy from a branch, branch main, folder /(root).
4. Save and wait for deployment.

Privacy:
- Original academic marksheets are intentionally excluded from this public package.
- Academic results are shown as summaries; original documents can be shared privately during recruitment.
- Review résumé and certificates for personal information before publishing.
- Social/contact icons are clickable.
- Project data is synthetic practice data, not real client data. Review all deliverables before interview use.
